# Rules & Guidelines

Aturan kerja sama dan pengembangan proyek:

1. **Tidak Ada Pembuatan Kode Otomatis**
   - Jangan membuat kode apa pun secara otomatis selama tidak diminta secara eksplisit (contoh kata kunci: *buatkan*, *kerjakan*).

2. **Mode Diskusi Default**
   - Setiap prompt adalah sesi diskusi. Jangan otomatis membuat kode apa pun tanpa instruksi eksplisit (sesuai poin 1).

3. **Batasan Perubahan Kode yang Terfokus**
   - Hanya lakukan perubahan pada kode yang sedang dibahas dalam diskusi.
   - Jangan mengubah kode lain yang sudah ada, kecuali memang memiliki keterkaitan langsung.

4. **Penanganan Prompt Singkat & Konfirmasi**
   - Jika pengguna mengirimkan prompt pendek (misalnya hanya 1 kalimat), ada kemungkinan pengguna hanya ingin melakukan konfirmasi.
   - Jangan meminta perizinan tindakan apa pun kecuali benar-benar diperlukan.
   - Konfirmasi terlebih dahulu sebelum memeriksa file jika diperlukan (contoh: *"Untuk memastikan fungsi tersebut saya perlu memeriksa file xxx, apakah boleh?"*).
